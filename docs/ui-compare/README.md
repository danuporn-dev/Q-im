## จุดที่ต่างจาก Figma และเหตุผล

**สีและตัวอักษร (D40)**
- ตัวอักษรบนพื้นส้มเป็นสีกรมท่าเข้ม `#181c2e` ไม่ใช่สีขาว เพราะตัวขาวบน `#ff7622` ได้ 2.67:1 ต่ำกว่าเกณฑ์ 4.5:1
- ตัวอักษรสีส้มใช้ `#b34400` และไม่ใช้สีเทาอ่อน `#a0a5ba` กับตัวอักษร เหตุผลเดียวกัน
- ปุ่มยกเลิก/ปฏิเสธสีเทาใช้ตัวอักษรเข้มแทนตัวขาว (ตัวขาวได้ 2.38:1)
- ฟอนต์ Prompt แทน Sen เพราะ Sen ไม่มีอักษรไทย

**ข้อมูล**
- ไม่ใช้รูป ชื่อร้าน ราคา คะแนน หรือข้อความตัวอย่างจาก Figma ทั้งหมดมาจากระบบจริง
- ยังไม่มีรูปอาหาร จึงแสดงแผ่นสีพร้อมชื่อเมนูแทน

**หน้าแรก**
- "All Categories" แบบการ์ดรูปพร้อมราคาเริ่มต้น เป็นปุ่มชื่อหมวด เพราะหมวดในระบบไม่มีรูปและราคา
- "Browse Stalls / See All" แสดงร้านทั้งหมดในหน้าเลย
- ไม่มีปุ่มเมนูสามขีด เพราะมีแถบเมนูด้านล่างแล้ว
- เพิ่มปุ่มแจ้งเตือน ซึ่งเป็นฟีเจอร์ที่ไม่มีในดีไซน์
- ทักทายด้วยชื่อ ไม่บอกช่วงเวลาของวัน
- แถบความหนาแน่นเรียงจากต่ำ (เขียว) ไปสูง (แดง) ส่วน Figma เรียงแดง-เหลือง-เขียว
- ทุกระดับมีข้อความกำกับ และในแถบมีเครื่องหมายชี้ระดับ จึงไม่ต้องพึ่งสีอย่างเดียว

**ค้นหา**
- ไม่มี "Recent Keywords" และ "Popular Right Now" เพราะระบบไม่เก็บประวัติค้นหาและยอดนิยม
- ผลค้นหาแสดงเป็นร้าน พร้อมชื่อเมนูที่ตรงคำค้น ไม่ใช่รูปเมนูแยกทีละรายการ

**อาหาร**
- เปิดเป็นหน้าต่างซ้อนบนหน้าร้านตามระบบเดิม ไม่ใช่หน้าใหม่
- ไม่มีปุ่ม "Buy Now" เพราะระบบไม่มีการสั่งข้ามตะกร้า

**ตะกร้าและชำระเงิน**
- รวมเป็นหน้าเดียวตามขั้นตอนเดิม
- ตัด Visa/Mastercard เพราะอยู่นอกขอบเขต
- ช่อง PromptPay แสดงเฉพาะร้านที่เปิดรับ

**ติดตามออเดอร์**
- ไม่มี "Find Seat" เพราะอยู่นอกขอบเขต
- ใช้เลขออเดอร์และหมายเลขคิวแทน Invoice
- เพิ่ม QR รับอาหารและ QR PromptPay ซึ่งไม่มีในดีไซน์

**ร้าน**
- ดีไซน์เป็นเฟรมมือถือ ระบบใช้ได้ทั้งแท็บเล็ตและเดสก์ท็อป จึงใช้แถบเมนูด้านข้างสีเข้มแทนแถบหัวสีขาวที่มีโลโก้ กระดิ่ง และเฟือง
- ตัด dropdown "Status" และลิงก์ "View All" ตามที่ตกลง บอร์ดแสดงทุกออเดอร์ใน 3 คอลัมน์
- "Manage Menu" และ "View Statistics" เป็นแท็บด้านข้าง
- รายละเอียดออเดอร์และการส่งมอบอยู่ในหน้าต่างส่งมอบที่มีอยู่เดิม ซึ่งมีปุ่ม "ได้รับเงินแล้ว"
- สถิติเป็นแท่งตามชั่วโมงอย่างง่าย (D33) ไม่มีกราฟเส้นและข้อมูลประเภทลูกค้า เพราะระบบไม่มีข้อมูลนั้น
- ตั้งค่าร้านเป็นฟอร์มเดิม ไม่มีหัวข้อโปรไฟล์ บัญชีรับเงิน หรือความปลอดภัย เพราะไม่มีฟีเจอร์เหล่านั้น

**หน้าที่ไม่มีดีไซน์:** ผู้ดูแล, เข้าสู่ระบบ, ข้อมูล, แจ้งเตือน, รายการโปรด, รีวิว และแถบโหมดสาธิต ใช้ token และคอมโพเนนต์ชุดเดียวกันทั้งหมด
